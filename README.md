# Paper PDF Reader

Windows x64 向けの論文 PDF ビューアです。段組のある本文を選び、翻訳した結果をハイライトのコメントとして PDF に保存できます。

## 使う

- ポータブル版は ZIP をフォルダーごと展開し、PaperPdfReader.exe を実行します。展開したフォルダーはそのまま移動できます。
- インストーラー版は setup.exe を実行します。ユーザー単位でインストールし、管理者権限は不要です。

両方に Python、Qt、MuPDF が入っています。PDF の閲覧と注釈の作成はオフラインで使えます。翻訳には別途 LM Studio または OpenAI 互換の翻訳サービスを設定してください。

Ctrl+O または exe への PDF のドラッグ＆ドロップで開きます。左のサイドバーには目次と注釈を表示し、上部のボタンから単ページと見開きを切り替えられます。未保存の変更はタブと上部に表示され、別の PDF に切り替えるときに保存するか確認します。Ctrl+F で文書内を検索できます。Ctrl+ホイールとピンチは、操作位置を中心とした拡大・縮小です。

ページをまたいで本文を選べます。右クリックから本文のコピー、文書内検索、Google 検索、注釈の作成、翻訳を選びます。コメントを手入力するにはハイライトを作り、左側の注釈カードに入力します。「翻訳…」では色を選び、原文と除外箇所を確認できます。「翻訳して注釈を追加」では、選んだ色でハイライトを作成して翻訳を開始し、訳文を同じ注釈に保存します。保存した注釈は標準 PDF のハイライトとコメントとして他のビューアでも読み取れます。

注釈一覧では Ctrl+クリックで選択を切り替え、Shift+クリックで連続する注釈を選べます。Ctrl+A では、絞り込み後の一覧に表示されている注釈をすべて選べます。選択中に一覧の上に出るボタンから、色の変更、翻訳、削除をまとめて実行できます。一括翻訳は現在の翻訳プロファイルを使い、各注釈のコメントに訳文を保存します。

設定で表示言語、翻訳サービスのプロファイル、本文の除外条件、ハイライトの不透明度を変更できます。

設定とバックアップは exe の横の data に保存します。そこに書き込めない場合は %LOCALAPPDATA%\PaperPdfReader を使います。

## 開発と配布ビルド

Windows x64 用の Python 3.12 で作業フォルダーに .venv を作り、次を実行します。

    .\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
    .\.venv\Scripts\python.exe run_reader.py [PDF]
    .\build.ps1

build.ps1 は PyInstaller のフォルダー形式で配布用の実行ファイル一式を作り、別の場所に ZIP を展開して描画と注釈保存を試験します。その後、同じ実行ファイル一式から Inno Setup 7 でインストーラーを作ります。ISCC.exe の場所が標準の場所と異なる場合は -IsccPath で指定できます。ポータブル版だけを作るときは -PortableOnly を指定してください。成果物は release に出力します。
