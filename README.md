# Paper PDF Viewer

Windows x64 向けの論文 PDF ビューアです。段組のある論文を読み、気になる箇所を翻訳して、訳文を PDF のハイライトにコメントとして保存できます。

## インストールと起動

- **ポータブル版**は ZIP を展開し、フォルダー内の `PaperPdfViewer.exe` を起動します。フォルダーごと別の場所に移動しても使えます。
- **インストーラー版**は `PaperPdfViewer-<バージョン>-setup.exe` を実行します。インストールはユーザー単位で、管理者権限は不要です。
- **以前のバージョンからの更新**では、以前のインストール先と設定を引き継ぎます。ポータブル版を新しいフォルダーに展開した場合は、以前の `data` フォルダーを新しい実行ファイルの横へ移すと、設定やバックアップを引き継げます。

両方に Python、Qt、MuPDF が入っています。閲覧と注釈の作成はオフラインで使えます。翻訳するには、設定で LM Studio などの OpenAI 互換サービスを指定してください。翻訳時は、選んだ文章を設定先のサービスへ送ります。

## 論文を読む

Ctrl+O で PDF を開けます。実行ファイルに PDF をドラッグして開くこともできます。左のサイドバーには目次と注釈を表示します。上部のツールバーでは移動、表示、倍率、検索の操作を縦線で区切っています。ウィンドウが狭いときは、一部のボタンが右端の「その他」に移ります。Ctrl+F で文書内を検索できます。Ctrl+ホイールとピンチ操作では、操作した位置を中心に拡大・縮小します。

PDF 本文にフォーカスがあるとき、「ページ全体に合わせる」表示か、矢印に対応する軸にスクロール範囲がなければ、←／↑ で前へ、→／↓ で次へ移動します。それ以外では矢印キーでスクロールします。矢印によるページ送りは移動履歴に追加されないため、引用先で数ページ読んだ後も Alt+← で引用元に戻れます。

本文中の引用や「図3」「Table 2」などをクリックすると、対応する参考文献や図表に移動できます。PDF に埋め込まれたリンクを優先し、リンクがない場合は本文と参考文献欄やキャプションを照合します。複数の参照があれば移動先を選べます。ハイライトの上でもリンクをクリックできます。ポインターを重ねると、埋め込みリンクには薄い色と枠、照合が必要な引用や図表参照には点線の枠が出ます。ツールバーの「戻る」（Alt+←）で元の位置に戻れます。照合は端末内で行い、文字情報のある PDF が対象です。

## 本文を選び、翻訳や注釈を付ける

ダブルクリックで単語、トリプルクリックで表示上の1行を選びます。2回目または3回目を押したままドラッグすると、単語または行単位で範囲を広げられます。通常のドラッグは文字単位です。選択はページをまたげます。

選んだ箇所を右クリックすると、コピー、文書内検索、Google 検索、注釈、翻訳を選べます。「ハイライトを作成」では色見本と色名から色を選び、注釈欄でコメントを加えられます。「翻訳…」では原文と翻訳から除外した箇所を確認できます。複数の段落を選んだときは、段落の区切りに空行を入れて翻訳へ送ります。数式、図表の文字、1 ページ目の著者・所属・受理日・脚注は、既定で翻訳から除きます。「翻訳して注釈を追加」では、翻訳を始めると同時にハイライトを作り、訳文をそのコメントに保存します。保存した注釈は、標準 PDF のハイライトとコメントとしてほかのビューアでも読めます。

注釈一覧では Ctrl+クリックで個別に選び、Shift+クリックで連続した範囲を選べます。Ctrl+A で絞り込み後の一覧をすべて選べます。色の変更、翻訳、削除をまとめて実行できます。一括翻訳は、使用中の翻訳プロファイルを使います。

注釈の編集は Ctrl+Z で元に戻し、Ctrl+Y または Ctrl+Shift+Z でやり直せます。PDF を開いている間は、保存後も履歴を使えます。未保存の変更はタイトルバーとタブに表示され、別の PDF に切り替えるときに保存するか確認します。追記保存に対応する PDF は、元のデータを保って変更分を書き足します。電子署名の設定によっては、別のファイルに保存する必要があります。

設定では、表示言語、翻訳サービスのプロファイル、翻訳から除く箇所、ハイライトの不透明度を変更できます。翻訳に使うプロファイルは「このプロファイルを翻訳に使う」で選びます。ほかのプロファイルを編集しても、使用中のプロファイルは変わりません。設定とバックアップは実行ファイルの横の `data` に保存します。そこに書き込めない場合は `%LOCALAPPDATA%\PaperPdfReader` を使います。

設定の「文字サイズ」タブでは、メニュー、ツールバー、タブ、目次、注釈、翻訳ウィンドウ、ダイアログ、お知らせの文字の大きさを、部位ごとに 50〜300% で変えられます。基準はお使いの Windows の既定の文字で、初期値は目次、注釈、翻訳ウィンドウが 130%、ほかは 100% です。各行の「初期値」ボタンと「すべて初期値へ戻す」で初期値に戻せます。変更は「保存」を押したときに、開いているすべてのウィンドウへ反映します。メニューとダイアログの文字は、読めなくなるほど小さくならないよう、最小で 7 pt にします。設定画面は、画面に収まる大きさまで自動で文字が縮みます。ファイルを選ぶ窓、ウィンドウの題名、起動時の失敗を知らせる窓の大きさは変えられません。Ctrl+, で設定を開けます。設定画面を開けなくなったときは、`settings.json` の `font` で始まるキーを消すと、初期値に戻ります。

## 開発・配布ビルド

Windows x64 用の Python 3.12 で `.venv` を作り、次を実行します。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements-build.txt
.\.venv\Scripts\python.exe run_reader.py [PDF]
.\build.ps1
```

`build.ps1` は PyInstaller で実行ファイル一式を作り、ポータブル版を別の場所に展開して描画と注釈保存を試験します。同じ実行ファイル一式から Inno Setup 7 でインストーラーを作ります。`ISCC.exe` が既定の場所にない場合は `-IsccPath` で指定します。ポータブル版だけを作る場合は `-PortableOnly` を指定してください。配布ファイルは `release` に出力します。
