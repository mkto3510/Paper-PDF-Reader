# 0.2.10 の GUI 修正

選択中の注釈を全文で読めるようにし，未保存の編集・訳文を黙って失わず，異常時に PDF 処理が止まらないようにする．表示言語を切り替えたときの言語の混在を減らす．変更は GUI 層（`paper_reader/` の `notes`・`window`・`dialogs`・`view`・`session`・`pane`・`translation`・`application`）で行い，PDF の保存形式と注釈データは変えない．`pdf.py` のエラー文は表示側で対応づけ，`pdf.py` 自体は変えない．高 DPI 対応は，描画の仕組みとキャッシュ容量の設計が要るため 0.2.11 で行う．

## 注釈カード

- 注釈を選択すると，コメント欄は内容に合わせて高さが伸びる．最小は現在の高さ（4行と余白）．最大は，注釈一覧の表示高さ（`Notes.viewport`）の70%で，超えたときだけ欄内でスクロールする．最大が最小を下回るときは最小にする．
- 高さは，`wrapped_document`（`sidebar.py`）で欄の幅に折り返した文書の高さに，枠と余白を足して求める．文字を入力するたび，および一覧の表示高さが変わったときに，そのカードを測り直し（`Notes.update_cards`），下の注釈の位置を更新する．
- 原文（英文）は，現在も `WrappedLabel` で高さに上限なく全文を折り返して表示する．この性質を保ち，選択前後で表示高さが原文に足りることを試験で確かめる．選択時に原文が欠けて見える報告があるため，再現して原因を特定する．原因が見つかれば直し，見つからなければリリース本文に「確認できなかった」と書く．
- 編集中に Esc を押して保存済みの内容へ戻した操作は，Ctrl+Z で取り消せる．戻す処理はカーソルによる置き換えで行い，フォーカスは編集欄に残す．戻したあと `modified` を解除し，取り消すと再び「変更あり」になる．

## 未保存の編集を守る

- 文書が残るタブ（同じ文書を別のタブでも開いている場合）を閉じるとき，そのタブのすべての注釈の下書きを，選択中の1件だけでなく `commit_drafts()` で文書に反映する．ここでの「保存」は文書（メモリ上の注釈）への反映で，PDF ファイルへの書き込みは従来の自動保存・手動保存が行う．反映が失敗した下書きは破棄されるので，失敗時はエラーを通知する．
- 翻訳ダイアログに `confirm_close()` を設ける．「未保存」とは，訳文・コメント欄の文字が，ダイアログを開いた時点のコメントと異なる状態，または翻訳が待機中・受信中の状態をいう．翻訳が終わって未保存の訳文が残っている場合も含む．原文欄の編集は含めない．
  - 未保存のとき，Esc，ウィンドウを閉じる操作（`reject()`），再度の「翻訳…」（`open_translation`），タブを閉じる操作（`close_tabs`）の前に確認を出す．選択肢は「続ける」と「破棄」．「続ける」が既定で，Esc 押下にも割り当てる．
  - 「続ける」では，元のダイアログを残して前面に出し，ほかの操作（新しいダイアログを開く，タブを閉じる）は行わない．タブを閉じる操作では，タブを1つも閉じる前に確認し，「続ける」なら閉じる処理全体を中止する．
  - 「破棄」では，受信中の翻訳を中止してダイアログを閉じる．
  - 「注釈に保存」は確認を出さない．
  - 未保存でなければ確認を出さず，従来どおり閉じる．
- 翻訳が待機中・受信中のあいだ，訳文欄を読み取り専用にする．翻訳が終了・失敗・取り消しのいずれかで読み取り専用を解除する．受信中の表示更新は従来どおり欄全体の置き換えでよい．
- 「名前を付けて保存」の挙動は変えない（書き出しだけで，開いているのは元のファイル，タブの「*」はそのまま）．別のファイルへ書き出せたときに，「コピーを保存しました。開いているのは元のファイルです。」と通知する．保存先が元のファイルと同じ場合（上書き保存になる）は通知しない．

## 設定と翻訳サービス

- 設定画面で，編集中のプロファイルと翻訳に使うプロファイルを分ける．開いた時点の使用プロファイルを保持し，保存時にもそれを使う．編集中のプロファイルにチェックボックス「このプロファイルを翻訳に使う」を置き，チェックしたときだけ使用プロファイルを切り替える．使用中のプロファイルは選択欄で「（使用中）」を付けて示す．使用中のプロファイルは，チェックを外して保存できない（常にどれか1つは使用中）．使用中のプロファイルを削除したときは，残った先頭のプロファイルが使用中になる．`settings.json` の形式は変えない．
- 保存時の検証は，プロファイルの名前・URL・追加の JSON・プロンプトに加え，原文の言語と翻訳先の言語が空でないことを調べる．失敗したときは，該当のプロファイルを選択し，メッセージに名前を示す．
- 原文・翻訳先の言語欄に，記入例（`en`，`ja`）を表示する．プロンプト欄の近くに，`${sourceText}`・`${langFrom}`・`${langTo}` を使えることを説明する．
- プロファイルを削除するときは確認する．プロファイルが1つしかないときは削除できず，その理由を通知する．
- 翻訳サービスが HTTP のエラーを返したときは，本文の JSON から理由を読み（`error.message`，文字列の `error`，`message`，`detail` の順），「HTTP 400: 理由」の形で表示する．JSON でない・空の本文のときは「HTTP 400」とする．接続テスト（モデル一覧）にも同じ形を使う．
- リダイレクトは，同じ送信元（スキーム・ホスト・ポート）への移動だけ追う（`SameOriginRedirectPolicy`）．別のホストへは追わず，API キーと本文を送らない．
- 「接続をテスト」の途中で設定画面を閉じたときは，返答を中断し，閉じたあとにコールバックを呼ばない．`models()` は中断のためのハンドルを返す．

## 表示と操作

- 文字情報のキャッシュ上限を，12ページと「表示中のページ数＋4」の大きい方にする．13ページ以上を選択して縮小しても，選択のハイライトがキャッシュの入れ替えで点滅しない．
- 最小化したウィンドウへ別の PDF を渡したとき，または開いている PDF の再表示を求められたときは，最小化だけを解除して前面に出す．最大化の状態は保つ．
- 位置の変更通知を変化時だけにする整理と，単ページ表示でのページ送りの間隔は，症状を再現できたときにだけ別途行い，この版の必須にはしない．

## 安定性

- PDF 処理の完了通知（コールバック）で例外が出ても，待機中の要求を処理し続ける．`_pump`・`_received`・`_stopped` のコールバック呼び出しをそれぞれ保護し，例外内容は標準エラーに出す（配布版は標準エラーがないため，無視する）．
- 閉じたビューが削除済みのときにコールバックが触れないよう，`view.py` の完了通知と `needed()` で，ビューが有効かどうかを `shiboken6.isValid` で確認する（`pane.py` と同じ方法）．
- タブの右クリックメニューは，対象のタブへ切り替えずに開く．「タブを複製」「別ウィンドウに複製」は，右クリックしたタブを対象にする．タブ切り替え時の保存確認は，従来どおり実際の切り替えだけで出す．
- タブの名前に含まれる `&` を，そのまま表示する（表示時に `&&` にし，比較も同じ文字列で行う）．
- PDF の読み込み中にウィンドウを閉じようとしたときは，閉じずに「読み込み中です。」と通知する．
- 確認ダイアログ（`confirm_discard`・`confirm_switch`）は，選択を読み取ったあとに `deleteLater()` で解放する．

## 言語と文言

- 表示言語を切り替えたとき，画面上の固定文が一方の言語に偏らない．日本語・英語の対応表を `messages.py` の1か所に集め（`Preferences.localize` と `Reader.error_text` から呼ぶ），日本語から英語，英語から日本語のどちらにも変換できるようにする．対象は `pdf.py`（開けなかった，PDF 処理が止まった）・`session.py`・`translation.py` の固定文，および `window.py` のプロパティ取得失敗．注釈カード・翻訳ダイアログ・設定画面の状態表示も，この関数を通す．サーバーの返答や OS のエラーなど，実行時に決まる文は変換しない．
- 署名付き PDF の確認（`window.py` の `QMessageBox.question`）と，ページ移動・倍率の入力ダイアログは，ボタンの文字を表示言語に合わせて指定する．ほかの標準ボタンの表示と，OS のファイルダイアログは，この版では変えない．
- 表記を「ウィンドウ」にそろえる（現在の「ウインドウ」を直す）．画面上の「Preferences」を「Settings」に，`dialogs.py` の文末の「．」を「。」にそろえる．
- 翻訳ダイアログの除外チェックボックスは，状態によらず1つの固定ラベルにする．日本語は「除外した箇所も翻訳に含める」，英語は「Include excluded text in translation」．
- ウィンドウタイトルは，文書を開いているとき「ファイル名 — Paper PDF Viewer」，状態があるときは「ファイル名 — Paper PDF Viewer — 状態」とする．文書がないときは従来どおり「Paper PDF Viewer」．
- ショートカット一覧に，矢印（スクロール），PageUp/PageDown（ページ送り），Esc（選択の解除・編集の取り消し），Ctrl+Enter（コメントの保存）を，日本語・英語の説明つきで加える．

## 今回は行わない

- 高 DPI 対応（0.2.11）．
- 保存中の「元に戻す」「やり直し」の通知（操作が無効になっているため通知を出せない）．
- 位置通知の整理（必要になったときだけ），選択ハイライトの再計算の省略，ページ送りの間隔（再現できたときだけ）．
- 未保存判定の一元化，注釈の選択状態の一本化，ウィンドウ位置の保存，アウトラインのキー操作，検索履歴の扱い，ピンチ操作の拡大率の計算式，「名前を付けて保存」の挙動変更．

## 検証

- 各項目に回帰試験を加える．試験のない項目（ツールバーの見た目，実際のアプリでの注釈カード）は，目視で確かめる．
