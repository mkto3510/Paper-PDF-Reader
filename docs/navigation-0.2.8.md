# 0.2.8 の文書内移動

文献・図・表の参照は，本文の文字位置と正規化したキーを移動先と照合する．注釈と PDF 内のリンクを優先し，未確定・重複した候補に移動しない．本文順の複数候補メニューと同一画面でも使える戻る・進むを用意する．

- 図表の章付き番号を最後まで読み，文として続く行や周囲と連続した本文をキャプション候補から外す．抽出フィルターと索引が同じ判定を使う．続き行を同じ段・ブロックで確認する．
- 図表と文献を独立に1ページずつ索引化する．図表は軽量な候補抽出の後に配置を確認する．文献は見出しと項目を検出し，見出しなしは末尾の連番3件と書誌根拠2件以上を要求する．
- 埋め込みの名前付き内部リンクを解決する．ページだけを指定するリンクは，そのページ内で同じラベルのキャプションに絞れる場合に表示位置を調整する．
- 描画・選択優先で，索引を世代内のタブ間で共有する．認識後150 msで待機表示，10秒で待機を終える．操作が変われば古い結果を無効化する．
- 色選択は色名と色見本を持つ通常の操作に統一する．現在色のアイコンと色フィルターを維持する．
- Sandwell の5箇所，既存8本，公開とローカルの正解付き試験，Windows の配布物を承認済みの 0.2.8 計画に従って検証する．
