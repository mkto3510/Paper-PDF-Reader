# 0.2.12 の GUI の文字サイズ

GUI の文字の大きさを，部位ごとに設定画面から変えられるようにする．設計と決定の経緯は [gui-font-size-design.md](gui-font-size-design.md) にある．この文書には，この版で変わったことと，検証の結果だけを書く．

## 変わったこと

- 設定画面に「文字サイズ」タブを足した．8 部位（メニュー，ツールバー，タブ，目次，注釈，翻訳ウィンドウ，ダイアログ，お知らせ）の倍率を，50〜300% の整数で個別に設定できる．各行に，実効サイズの表示，その行だけに効く見本の文字，「初期値」ボタンがある．タブの下に「すべて初期値へ戻す」がある．
- 実効サイズは「基準フォント × 倍率」で，0.5 pt 刻みに丸める．基準フォントは，起動時に 1 回だけ，Windows の既定の文字から取る．
- 初期値は，目次・注釈・翻訳ウィンドウが 130%，ほかが 100%．旧版の `settings.json` からの更新でも，黙って適用する．保存するまで設定ファイルは書き換わらない．初期値と同じ値は，ファイルに書かない．
- 「保存」を押したときだけ，開いている全ウィンドウと翻訳ウィンドウに反映する．書き込みに失敗したときは，何も反映しない．複数の設定画面を開いていても，保存は自分で変えた文字サイズの行だけを書くので，別のウィンドウの保存を戻さない．
- メニューとダイアログの実効サイズには，下限 7 pt を掛ける．設定画面は，画面に収まる大きさまで自分の文字を下げる．`Ctrl+,` で設定を開ける．
- ツールバーのアイコンは，ツールバー部位の倍率に合わせて大きくなる（段階 16/20/24/28/32/40/48 px）．メニューのアイコンは 16 px のまま．
- メインウィンドウには基準サイズの「地」を付けた．ダイアログ部位を変えても，主ウィンドウの本体は動かない．
- Windows 11 のスタイルは，メニューバーの項目の文字を固定の大きさで描くので，メニュー部位を変えたときだけ，文字を自分で描く（`MenuBarFontStyle`）．
- 文字が大きくなると切れていたレイアウト（注釈カードの入力欄，ボタン群，色の絞り込みボタン，目次，ページ欄，設定画面の入力ボックス，翻訳ウィンドウの引用欄）を，文字に合わせて測り直す．

## 今回は行わない

- 全体の倍率，Ctrl+/- 系のショートカット，設定画面でのプレビュー．
- Qt が内部で作る右クリックメニュー（入力欄など）をメニュー部位に従わせること．これらはダイアログ部位に従う．
- 設定画面以外のダイアログを画面に収める処理．
- 保存済みの翻訳ウィンドウの大きさ（`dialogSize`）の変更．

## 検証

- `tests/check_gui_fonts.py`（新規）: 設定の読み込みと保存，実効サイズ，アイコンの辺，起動時のダイアログのフォント，設定画面の保存と画面への収まり，地と各部位の独立，カードの測り直し（フォーカス，取り消し履歴，スクロール位置），翻訳ウィンドウの大きさ，メニューとタブ，メニューバー，ツールバーのアイコン．
- 既存の試験は，すべて通る．`check_chrome_notes.py` は，同じ「中程度の長さ」の文章が 130% で高くなるので，繰り返しの回数を減らした．`check_citations_viewport.py` は，`AreaMenu` に合わせて差し替え先を直した．
- 実機の Windows 11 で，メニューバーの 100%・200%・300% の描画，選択中の背景，最小の高さと幅を確かめた．
- 未確認: OS の「テキストのサイズ」，OS の表示倍率 125%・150% そのもの，メニューバーの押下とライトモードの見た目，Alt キーでメニューバーへ移れること．
